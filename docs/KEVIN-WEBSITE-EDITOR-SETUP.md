# Kevin's website editor setup

Use this checklist to set up and edit the Jollytails Resort website.

## One-time setup

- [ ] Create or sign in to your own personal GitHub account.
- [ ] Accept Pamela's invitation to collaborate on `gogopammy/jollytails-resort`.
- [ ] Install and sign in to GitHub Desktop.
- [ ] In GitHub Desktop, clone `gogopammy/jollytails-resort` to your computer.
- [ ] Open the cloned repository in Codex.

You do not need access to Pamela's Vercel account. Pamela retains control of Vercel, the domain and DNS, billing, and deployment settings.

## Making a website update

- [ ] In GitHub Desktop, fetch or pull the latest changes before you begin.
- [ ] Open the local Resort repository in Codex and make the requested website edits.
- [ ] Review and preview the changes before publishing them.
- [ ] Commit the changes to `main` with a short, clear description.
- [ ] Push the commit to GitHub using GitHub Desktop.
- [ ] Confirm that the public website updates after Vercel's automatic deployment completes. If it does not, tell Pamela; she manages the deployment settings.

## Keep private information out of GitHub

Do not add credentials, passwords, private customer or staff information, API secrets, `.env` secrets, or other sensitive material. Public website copy, HTML, CSS, JavaScript, public images, and non-sensitive configuration are fine to commit.
