# Asset provenance

All assets in this directory are Jollytails Resort assets. No corporate `jollytails.ca` photography is included.

## `jollytails-resort-logo-transparent.png`

Transparent-background version of the current Resort logo, prepared from the Resort-owned logo artwork for the header and footer. It remains independently swappable through the shared logo styling.

## `resort-dogs-hero.jpeg`

Full-resolution homepage hero photograph supplied directly by the Resort owner on 2026-09-06. The image shows two golden retrievers relaxing together, with a border collie and other daycare guests in the Resort’s outdoor turf play area.

## `boarding-dog.webp`

A dog resting on a bed, published as the current Resort homepage boarding photograph.

Source: `https://www.jollytailsresort.ca/`
